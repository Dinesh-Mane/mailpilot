# MailPilot
### MailPilot is an AI-powered email assistant that understands incoming emails and generates context-aware replies, available as a web application as well as a Chrome extension that seamlessly integrates with Gmail.  
**Tech:** React.js, Large Language Models, Java, Spring Boot, Spring AI, Google GenAI models (gemini-3.6-flash), Tailwind CSS, Axios.
